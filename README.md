## Projeto em destaque

### [AutoFlow — automação administrativa](https://github.com/Diogo-Borges652/autoflow)

Pipeline em Python que importa CSV/XLSX, valida campos, identifica registros duplicados e consolida receitas e despesas com precisão decimal. Gera relatórios em CSV, XLSX, JSON e HTML, com rastreabilidade por linha e exemplos fictícios.

**Competências demonstradas:** modelagem de regras de negócio, processamento de dados, tratamento de falhas, testes unitários e de integração, empacotamento Python e GitHub Actions.
